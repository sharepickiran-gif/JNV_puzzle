# JNV Campus Puzzle

## Run the puzzle

The puzzle needs the local server to discover images in the `images` folder.
From this folder, run:

```powershell
python server.py
```

Then open <http://127.0.0.1:8000> in your browser. Add supported image files
(`.png`, `.jpg`, `.jpeg`, `.gif`, `.webp`, or `.bmp`) to `images`. Click **New
Image** to refresh the available images without restarting the server or page.

Press Ctrl+C in the terminal to stop the server.
